# HexRun 多面体翻滚障碍模拟

HexRun 是一个基于原生 JavaScript、Canvas 和 Three.js 的浏览器小游戏。玩家控制一个小斜方截半立方体（Rhombicuboctahedron）沿真实接触边连续翻滚，在无尽赛道中躲避障碍，或在随机迷宫中寻找终点。

## 游戏功能

### 赛道竞速模式

- 16 条并列道路和 120 格有限赛程，所有参赛物体从同一条起跑线出发。
- 可直接输入 1–8 个翻滚物体同时比赛；所有物体在同一起跑线列队并同时出发。
- 赛道前方设有黑白方格终点线，HUD 显示领先进度和完赛数量。
- 已完赛物体继续占用终点安全区，后到物体必须选择相隔至少两道的终点位置，不能在终点重叠。
- 进入终点前最后六格时会预约并锁定安全终点车道；受阻时等待，不会在已完赛物体后方左右循环变道。
- 障碍物具有不同的纵向长度，并可横跨多条道路；宽度遵循“基础障碍宽度 + n 倍道路宽度”。
- 障碍带比此前更密集，相邻障碍带间距按 4 个物体边长的整数倍生成；每带保留足够的连续通路，避免安全区规则造成永久堵塞。
- 每个物体会自主判断障碍、相邻参赛物体及其他物体已预留的目标位置；任何物体当前位置和目标位置周围前后、左右 `±1` 格组成的 `3×3` 区域都禁止其他物体进入。
- 遇到横跨多道的障碍后会记住选定的绕行方向，临时受阻时等待而不是左右反复变道。

### 地图模式

- 每次重置都会生成一张 21×21 的大型随机障碍地图。
- 先创建与地图同为 21×21 的二维布尔数组，内部格子以 32% 的概率生成障碍点，地图边缘保持开放；单格孤立点也会保留并构造成独立障碍。
- 四方向相邻的障碍点会合并为连通块，再沿每个连通块的边界构造横平竖直的薄墙。
- 每次生成后都会验证开放区域整体连通；不满足条件时自动重新生成，保证所有起点都能到达共同终点，同时保留环路和多条可选路线。
- 赛道模式支持 1–8 个物体，地图模式支持 1–20 个物体；地图起点会尽量分散，并在移动时避开其他物体的安全范围。
- 地图模式会显示策略切换按钮，可在 A* 寻路和自主探索之间即时切换；赛道模式隐藏该按钮。
- A* 模式会用与物体一一对应的彩色发光点显示实时规划路线；每次避让重算后同步更新，2D 与 3D 视图均可见。
- A* 全局规划只考虑固定障碍，因此路线不会被其他物体的瞬时位置扰动；移动前仅检查下一格，短暂占用时等待，持续互堵时由局部避让让出一格后再计算静态最短路。
- 局部避让带有等待超时恢复：即使遇到多物体等待链，长时间未移动的物体也会主动让出安全格并重新接入最短路径，避免非终点物体无限停住。
- 自主探索为每个物体维护独立的格子访问次数，优先进入未访问格；没有新格时选择访问次数最少的安全相邻格，再用终点距离和随机值打破平局，全程不预先计算完整路径。
- 除共同终点外，物体不能处在同一格或上下左右相邻格；斜对角位置允许同时存在物体，终点允许多个物体重叠到达。
- HUD 实时显示到达数量和所有物体的累计步数。
- 地图模式使用固定在地图中央的高位总览相机，不跟随任何物体；缩放半径范围扩大到 3–420。

### 多面体运动

- 运行时构造小斜方截半立方体的 24 个顶点、26 个面和 48 条边。
- 每次翻滚根据当前接地面、移动方向和相邻面动态计算旋转轴与角度。
- 一个逻辑移动由两次连续翻滚组成，使多面体重新稳定落在轴对齐的方形面上。
- 使用缓动动画、接触阴影和逐面配色表现翻滚过程。

### 显示与交互

- Three.js 3D 透视视图，支持平滑跟随镜头。
- Canvas 2D 俯视视图，与 3D 视图共享同一份实时游戏状态。
- 鼠标拖动可旋转和调整镜头俯仰角，滚轮可缩放。
- 初始相机沿赛道方向观察，横向聚焦点始终保持在赛道中间，纵向位置跟随最前方物体的前进距离，并向领先位置前方预留四格视野。普通拖动旋转，按住 `Shift` 拖动平移，滚轮缩放；操作停止约 5 秒后恢复自动跟随。
- 支持暂停、重置、玩法切换、参赛数量输入以及再次翻倍后的慢、正常、快三档速度。
- Three.js 已包含在 `vendor` 目录中，运行时不依赖外部 CDN。

## 操作方式

| 操作 | 按键或控件 |
| --- | --- |
| 旋转/俯仰 3D 镜头 | 鼠标拖动 |
| 缩放 3D 镜头 | 鼠标滚轮 |
| 切换 2D/3D | `Alt + 3` |
| 暂停、模式、重置、速度 | 页面顶部控件 |

游戏中的翻滚与避让均为自动运行，不再区分自动和手动模式。

## 启动

项目使用浏览器 ES Modules，需要通过本地 HTTP 服务访问。项目目录中执行：

```powershell
python -m http.server 8000
```

然后打开 <http://localhost:8000/>。

项目无需安装依赖或执行构建命令。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构、HUD、控制栏和模块入口 |
| `style.css` | 全屏画布及界面样式 |
| `js/main.js` | 页面事件绑定和统计数据显示 |
| `js/game.js` | 游戏状态、玩法逻辑、输入、镜头和主循环 |
| `js/geometry.js` | 多面体拓扑生成和 Three.js 网格构建 |
| `js/roller.js` | 基于接触边的翻滚运动计算 |
| `js/maze.js` | 迷宫生成、BFS 和 A* 寻路 |
| `js/renderer2d.js` | 与 3D 状态同步的 Canvas 2D 渲染 |
| `vendor/` | 本地 Three.js 模块 |
